# G.I. SEA VISTA Website

Landing page for **G.I. SEA VISTA CO., LTD.** — Phuket jet ski tours.

## Stack

- React + Vite + TypeScript + Tailwind CSS v4
- Motion (Framer Motion)
- [Lucide Icons](https://lucide.dev/icons/)
- UI patterns from [21st.dev / Magic UI](https://21st.dev/community/components) (MIT):
  - [Shimmer Button](https://21st.dev/@dillionverma/components/shimmer-button)
  - [Shiny Button](https://21st.dev/@dillionverma/components/shiny-button)
  - [Blur Fade](https://21st.dev/@dillionverma/components/blur-fade)
  - [Number Ticker](https://21st.dev/@dillionverma/components/number-ticker)
  - [Marquee](https://21st.dev/@dillionverma/components/marquee)

## Run

```bash
cd web
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Content

Copy and contact details come from `src/content.ts` (TH / EN). Brand images live in `public/images/`.
